Detail screens (Purchase order, Vendor, Production run, Count sheet): header with status-driven actions (one primary, destructive actions as `button--danger`), `facts` list, main table or form on the left and a `timeline` of status history on the right from 64rem.

- Quantity inputs in `line-grid` tables are 5rem wide, right-aligned, tabular figures, labelled for screen readers.
- The timeline is a 1px rule with ring markers; the latest event has a clay-filled marker.
