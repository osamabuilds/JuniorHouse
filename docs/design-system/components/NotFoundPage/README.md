The two "this address has no page" states. They are **real status codes**, never a "not found" page served with 200 (CLAUDE.md): an unknown address answers **404**, a permanently removed product answers **410**.

- **404.** A large `404` in the display face (decorative, `aria-hidden`), `display-md` "We could not find that page", one sentence, a search field, a marigold **Back to home** and the top-level links. Errors say what to do next.
- **410, product removed.** "This piece has left the collection", one sentence, **Shop girls**, and a "Similar pieces" row so the shopper keeps going. A product that has moved is a 301, not this page.
- A temporary failure is a 503 with "Something went wrong. Please try again in a moment." in the same layout.

One `<h1>` per page, full header and footer, `noindex`. Placeholders: product names.
