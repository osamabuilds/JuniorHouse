The Romp Kids logo. Files are in [`../../brand/`](../../brand): `romp-kids-horizontal`, `romp-kids-stacked`, `romp-wordmark`, `romp-symbol`, each in colour (`-color`), one-colour ink (plain) and each with a `-reversed` version for dark grounds.

**The mark.** A lowercase, geometric "romp" drawn from round-capped strokes of one weight (no font is needed), ending in a ball resting just above its shadow: the "romp" is the bounce. In the **colour** version each letter has its own colour: coral `#F2553D`, sun `#FFB000`, sky `#1E9BE8`, green `#22B573` and a violet `#7B4DFF` ball (lifted tones `#FF6F59 #FFC233 #4DB5F5 #3ED598 #9B7BFF` on dark). Colour is the primary logo, because this is a children's brand. **KIDS** is the same stroke weight, tracked caps, set small. The symbol is the "r" with the ball and shadow on a rounded square, for the favicon, app icon and avatars.

**Use**
- **Colour.** Use the colour logo on white or ink grounds. Use the one-colour version (ink on white, white on ink) where colour cannot print or must be quiet: stamps, embossing, receipts, a single-colour label. The shadow is the ball's colour at 50%. Never a gradient, never outlined, never recoloured letter by letter in other colours.
- **Colour stays in the logo.** The storefront and admin interface remain black and white, with marigold only for controls; the logo's colours are not UI tokens.
- **Which one.** Horizontal in the header and footer when "Kids" should show; stacked on packaging, labels and social avatars; wordmark alone where the site is already clearly Romp; symbol under 32px.
- **Clear space.** The height of the "o" on every side. **Minimum size.** Wordmark 64px wide, horizontal lockup 160px, symbol 16px.
- **Do not** stretch, rotate, recolour, add effects, replace the ball with another shape, or retype it in a font.
- Alt text: "Romp Kids" (or "Romp, home" when it is the home link). A decorative repeat uses `alt=""`.
