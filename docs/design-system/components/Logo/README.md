The Romp Kids logo. Files are in [`../../brand/`](../../brand): `romp-kids-horizontal`, `romp-kids-stacked`, `romp-wordmark`, `romp-symbol`, each as ink (`.svg`) and reversed (`-reversed.svg`).

**The mark.** A lowercase, geometric "romp" drawn from round-capped strokes of one weight (no font is needed), ending in a ball resting just above its shadow: the "romp" is the bounce. **KIDS** is the same stroke weight, tracked caps, set small. The symbol is the "r" with the ball and shadow on a rounded square, for the favicon, app icon and avatars.

**Use**
- **Colour.** Ink `#111111` on white, white on ink. The shadow is the logo colour at 50%. The logo is never marigold, never a gradient, never outlined.
- **Which one.** Horizontal in the header and footer when "Kids" should show; stacked on packaging, labels and social avatars; wordmark alone where the site is already clearly Romp; symbol under 32px.
- **Clear space.** The height of the "o" on every side. **Minimum size.** Wordmark 64px wide, horizontal lockup 160px, symbol 16px.
- **Do not** stretch, rotate, recolour, add effects, replace the ball with another shape, or retype it in a font.
- Alt text: "Romp Kids" (or "Romp, home" when it is the home link). A decorative repeat uses `alt=""`.
