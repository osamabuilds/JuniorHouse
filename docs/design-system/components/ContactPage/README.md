The contact page: a form and the other ways to reach the business. The contact **facts** (WhatsApp, email, hours) are settings records and render only when entered (the page shows nothing for a missing fact).

- **Form.** Name, email, topic (select), optional order number, message, one marigold **Send message**. Labels sit above fields, errors under them with an instruction.
- **Aside.** A box of fact rows and a line pointing to Delivery and Exchanges.

Rules: the form needs spam protection and a confirmation state (not drawn); no contact fact is typed into the template (SC-14); the message is stored and a copy is not logged with personal data (SEC-25).
