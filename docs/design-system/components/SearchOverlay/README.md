Search is prominent: a visible field on desktop, an icon on phones. Both open the same overlay.

- Overlay: `surface`, full viewport. Top row: a 28px serif input (autofocus, `type="search"`) and a close button. Body: "Popular" chips and up to four suggested product cards (two across on phones, three to four on desktop; cards use the standard 4:5 image). Suggestions update as the person types, after 200ms.
- Esc or the close button closes it and returns focus to the trigger. Enter goes to the results page. Empty results show "Nothing for 'x'" in `display-sm` with links to New in, Girls, Boys, Baby and Gifts.
