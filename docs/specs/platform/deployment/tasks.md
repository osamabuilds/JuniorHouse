Steps D1 to D7 need no provider account and are rehearsed on a local compose run. D8 to D12 need the owner actions in [../tasks.md](../tasks.md).

- [ ] D1. `SiteOptions` (`Site:PublicBaseUrl`, https outside Development) and the single variable `ROMP_PUBLIC_HOST` feeding allowed hosts, allowed origins (development only), cookie domain (host-only by default) and the proxy server name. Test: `SiteOptionsValidatorTests.HttpsRequiredOutsideDevelopment`, `HostConfigurationTests.NoHostnameLiteralInSource` (scans source and committed config for a hostname literal, AC-16).
- [ ] D2. `migrate` host verb: runs every module's migrator, exits non-zero on failure; start-up migration stays Development-only. Test: `MigrateVerbTests.AppliesAllModules_AndFailsLoudly` (Testcontainers, AC-5).
- [ ] D3. Test: `ProxyConfigTests.HasRequiredHeaders_AndProxiesApi` (renders the template and checks it, plus `nginx -t` in the container), `smoke.sh` run locally (AC-2, AC-3, AC-11).
